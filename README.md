# KSIJ Mumbai

This project uses the Next.js App Router with JavaScript page files. The existing page content, styling, assets, and browser interactions are preserved.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Pages

- `/` — Home
- `/donate` — Donation
- `/projects` — Projects
- `/lifetime-membership` — Lifetime Membership
- `/qaumi-sahayak` — Qaumi Sahayak

The page routes live in `app/`, preserved page content is stored in JavaScript modules under `content/`, and public images and browser scripts live in `public/`.
